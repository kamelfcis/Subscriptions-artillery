# خطوات التشغيل على جهاز العميل (مرة واحدة بالترتيب)

نفّذ الخطوات التالية **بالترتيب**. لا تعدّل قاعدة البيانات القديمة `Subscriptions` — النظام القديم يبقى يعمل كما هو.

---

## 0) المتطلبات قبل البدء (ثبّتها أولاً)

شغّل الملف التالي **كمسؤول** ليثبّت كل المطلوب دفعة واحدة:

`deploy\setup needs\SetupNeeds.exe`

| المتطلب | الإصدار المطلوب | ملاحظة |
|---------|------------------|--------|
| Windows | 10 / 11 أو Windows Server | جهاز السيرفر |
| .NET 8 SDK | **8.0.x** (مثلاً 8.0.428) | لبناء/تحديث وكيل الطباعة |
| Node.js | **20.17.0 أو أحدث** (مثبت: Node 20) | السيرفر والواجهة |
| npm | يأتي مع Node | تثبيت الحزم |
| PM2 | **5.x** | اختياري لإدارة Node؛ التشغيل الافتراضي عبر `Install-WindowsServices.bat` |
| ODBC Driver | **17** أو **18** لـ SQL Server | اتصال قاعدة البيانات |
| sqlcmd | Microsoft Sqlcmd | تطبيق سكربت الجداول |
| winget | App Installer | يستخدمه `SetupNeeds.exe` للتنزيل |
| SQL Server | موجود على الشبكة/الجهاز | مع قاعدة للاستخدام |
| PowerShell | مدمج مع ويندوز | سكربتات التثبيت |
| متصفح | Chrome / Edge | أجهزة الموظفين |

بدون إنترنت: ثبّت نفس الأدوات يدوياً من مواقع Microsoft / Node.js ثم أكمل من الخطوة 1.

---

## 1) عمل نسخة احتياطية من قاعدة البيانات الحية

1. افتح **SQL Server Management Studio** على جهاز السيرفر.
2. انقر يمين على قاعدة **Subscriptions** ← **Tasks** ← **Back Up…**
3. احفظ ملف النسخة في مجلد معروف (مثلاً `D:\SubscriptionsBackups`).
4. انتظر حتى تنتهي النسخة بنجاح.

---

## 2) استعادة النسخة باسم جديد (مثلاً Subscriptions_New)

1. في نفس البرنامج: انقر يمين على **Databases** ← **Restore Database…**
2. اختر ملف النسخة من الخطوة 1.
3. في اسم القاعدة اكتب اسماً جديداً، مثلاً: **Subscriptions_New**  
   (يمكنك اختيار اسماً آخر — المهم ألا يكون `Subscriptions` حتى لا يُمس النظام القديم.)
4. أكمل الاستعادة وتأكد أنها نجحت.
5. من الآن فصاعداً: المنظومة الجديدة تستخدم **Subscriptions_New** فقط. قاعدة **Subscriptions** تبقى للنظام القديم بدون تغيير.

---

## 3) نسخ مجلد المشروع إلى السيرفر

1. انسخ مجلد المشروع كاملاً (الذي بداخله `deploy` و `server` و `web`) إلى جهاز السيرفر، مثلاً:
   `D:\subscriptions-enterprise`
2. تأكد أن المجلد `deploy` موجود بداخله.

---

## 4) تشغيل التثبيت (كمسؤول) على القاعدة الجديدة

1. افتح المجلد: `deploy\client-online-install`
2. انقر يمين على **Install-ClientOnline.bat** ← **Run as administrator**
3. عندما يسألك عن سيرفر SQL: اكتب اسم الجهاز أو عنوانه (أو Enter للاقتراح).
4. عندما يسألك عن اسم قاعدة البيانات: اكتب **Subscriptions_New** (أو الاسم الذي اخترته في الخطوة 2) — **لا تكتب Subscriptions**.
5. أكمل الشاشات (تثبيت Node إن لزم، ثم التثبيت).
6. بيانات الدخول الافتراضية بعد التثبيت:
   - المستخدم: **admin**
   - كلمة المرور: **12345678** (الأرقام من 1 إلى 8 بالترتيب)
   إذا أدخلت كلمة مرور أخرى أثناء التثبيت فاستخدمها بدل الافتراضية.

---

## 5) تسجيل الخدمات لتعمل مع ويندوز (كمسؤول)

1. افتح المجلد: `deploy`
2. انقر يمين على **Install-WindowsServices.bat** ← **Run as administrator**
3. انتظر حتى تظهر رسالة النجاح.

بهذا يعمل السيرفر والواجهة ووكيل الطباعة تلقائياً عند تشغيل الجهاز.

---

## 6) ضبط عنوان IP السيرفر لوكيل الطباعة

وكيل الطباعة (**CardPrintAgent**) يجب أن يعمل على **الجهاز المتصل بطابعة الكروت** (عادة جهاز السيرفر نفسه).

1. اعرف عنوان IP السيرفر: افتح **cmd** واكتب `ipconfig` وانسخ عنوان IPv4 (مثلاً `192.168.1.50`).
2. افتح الملف النصي (أنشئه إن لم يوجد):
   `deploy\client-online-install\payload\print-agent\PRINT_AGENT_HOST.txt`  
   واكتب فيه عنوان IP السيرفر فقط، مثلاً:
   ```
   192.168.1.50
   ```
   أو اكتب `+` ليستمع على كل عناوين الشبكة (الأبسط غالباً).
3. افتح (أو أنشئ) الملف:
   `web\.env.local`   
   وتأكد من وجود هذين السطرين (بدّل الرقم بعنوان السيرفر الحقيقي):
   ```
   VITE_API_BASE=/api
   VITE_PRINT_AGENT_URL=http://192.168.1.50:5678
   ```
4. من مجلد `deploy\client-online-install` شغّل:
   `scripts\Start-PrintAgent.ps1`  
   (أو أعد تشغيل مهمة الطباعة من الخطوة 5).
5. انسخ مفتاح الطباعة من الملف:
   `deploy\client-online-install\payload\print-agent\PRINT_AGENT_KEY.txt`  
   ستحتاجه داخل شاشة طباعة الكارنيه في الموقع.

**مهم:** وكيل الطباعة يعمل على المنفذ **5678**. الطباعة تتم من الجهاز الذي فيه الطابعة فقط.

---

## 7) الدخول من أي جهاز على الشبكة

1. من أي جهاز على نفس الشبكة افتح المتصفح على:
   `http://عنوان-IP-السيرفر:5173/`  
   مثال: `http://192.168.1.50:5173/`
2. سجّل الدخول بمستخدم **admin** وكلمة المرور **12345678** (ما لم تغيّرها أثناء التثبيت).
3. غيّر كلمة المرور بعد أول دخول من قائمة المستخدم في الشريط العلوي.
4. لطباعة الكروت: الصق مفتاح `PRINT_AGENT_KEY` في نافذة الطباعة، وتأكد أن وكيل الطباعة يعمل على جهاز الطابعة.

---

## تذكير سريع

| ماذا | أين |
|------|-----|
| القاعدة القديمة (لا تلمسها) | `Subscriptions` |
| القاعدة الجديدة للمنظومة | `Subscriptions_New` (أو اسمك) |
| رابط الموقع للموظفين | `http://IP-السيرفر:5173/` |
| دخول المدير الافتراضي | `admin` / `12345678` |
| وكيل الطباعة | جهاز الطابعة — منفذ 5678 — يحتاج المفتاح |
| ملف IP للطباعة | `deploy\client-online-install\payload\print-agent\PRINT_AGENT_HOST.txt` |
| عنوان الطباعة في الموقع | `web\.env.local` ← `VITE_PRINT_AGENT_URL` |
