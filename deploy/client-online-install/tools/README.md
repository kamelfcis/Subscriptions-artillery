# Service wrapper tools

`Install-WindowsServices.ps1` downloads **WinSW** (`WinSW-x64.exe`) into this folder on first run (needs network once, or drop the EXE here offline).

- Upstream: https://github.com/winsw/winsw/releases  
- Used as: `services\SubscriptionsAPI.exe` and `services\SubscriptionsWeb.exe` (copies of WinSW beside each XML).
